table.csv: tabla usada para SIRIO

Ejecutamos SIRIO para tres geometrías del campo magnético estelar: dipolar, espiral de Parker y PFSS híbrida.


En el nombre de los gráficas de indica el nombre de la estrella y además se añade "Earth" para un planeta de tipo terrestre y "Jupiter" para un planeta de tipo Júpiter. 

El nombre de las gráficas sigues la estructura "Flux_D_ORB_"Nombre del objeto"_"Earth/Jupiter"-"geometría magnética"-Bstar"intensidad campo magnético estelar"G-Bplanet["campo magnético planet"]G-"rango eficiencia"-T_corona"temperatura corona"SPI_at_"altura a la que tiene lugar SPI, desde el centro de la estrella"R_star_freefree.pdf

Por ejemplo:

Flux_D_ORB_2MASS_J04244506+2701447_Earth-closed-dipole-Bstar2000.0G-Bplanet[0.400]G-1.0e-03-2.0e-03-T_corona1.5MKSPI_at_1.0R_star_freefree.pdf

para la estrella 2MASS_J04244506+2701447, un planeta terrestre, geometría dipolar, Bstar=2000G, Bplanet=0.4 G, Beta=1e-3 a 2e-3, Tcor=1.5MK, SPI en la superficie estelar.
